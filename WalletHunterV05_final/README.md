# Wallet Hunter V07

Персональный Telegram copy trader для Hyperliquid. Каждый Telegram user получает
изолированный интерфейс, свой target Hyperliquid account и до трёх leader wallets.
Пользователи не видят, не меняют и не используют данные друг друга.

## Как работает копирование

- Для каждого из 1–3 leaders выделяется одинаковая доля всего баланса target account.
- Берётся реальный процент маржи, использованный leader-ом.
- Этот процент применяется к выделенной доле target account, затем умножается на
  копируемое плечо (ограниченное `MAX_LEVERAGE`).
- Если несколько leaders торгуют одним рынком, их целевые объёмы неттируются.
- `MAX_TOTAL_EXPOSURE_USD` ограничивает суммарную целевую экспозицию аккаунта.
- Бот изменяет только позиции, которые сам открыл; ручная позиция на том же рынке
  блокирует копирование и не затрагивается.
- Переключатель Futures/XYZ ставит соответствующий рынок на hold: новые входы и
  изменения не выполняются, уже открытые позиции не закрываются автоматически.

При `AUTO_TRADING=false` бот работает в paper mode. Начинайте только с него и
переключайтесь на live после проверки target account и расчётов.

## Риск и контроль

- Три риск-профиля: консервативный, стандартный и агрессивный. Они ограничивают
  размер копирования, число позиций, долю одного актива и допустимый дневной убыток.
- При достижении дневного лимита бот прекращает открывать и изменять позиции до
  следующего дня; уже открытые позиции не закрываются автоматически.
- `Emergency stop` выключает копирование и отменяет resting-ордера. Отдельная
  подтверждённая кнопка дополнительно закрывает только позиции, которыми управляет бот.
- В панели есть журнал последних 200 операций, ручные отчёты за день и неделю,
  а также автоматические ежедневный и еженедельный Telegram-отчёты после 20:00.

## Telegram

Нажмите `☰ МОЙ COPY TRADER`, затем:

1. Подключите свой target Hyperliquid account в формате `Название | 0xADDRESS | API_PRIVATE_KEY`.
2. Добавьте от одного до трёх leader wallets.
3. Проверьте каждого leader-а через «Анализ leader за 90 дней».
4. Включите копирование.

Анализ использует хронологические closing fills с `closedPnl`, считает PF,
expectancy, win rate, maximum drawdown, Sharpe, стабильность по торговым дням и
концентрацию результатов, а также показывает текущие открытые позиции leader-а.

## Запуск

```bash
./deploy_v05.sh
cp .env.example .env
nano .env
source .venv/bin/activate
python desktop/main.py
```

Для реальной торговли задайте `AUTO_TRADING=true` только после paper-теста.
`ENTRY_PRICE_TOLERANCE_PCT` ограничивает первый вход, если цена уже сильно ушла
от усреднённой цены входа leader-а.

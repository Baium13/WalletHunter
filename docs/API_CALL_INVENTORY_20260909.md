## Important qualifications

- `scripts/recover_ownership.py::info` is an old, **operator-only** urllib path with hardcoded audited positions. It is not a service and was not executed. It does not use the host governor; it must not be run concurrently without budget coordination. No normal execution bypass was found; `core/legacy_route_calls.py` is injected by isolated tests only.

- Metadata-only shared cache: exact URL/network/type/dex key, fixed 30-second expiry, bounded 1-second wait, 30-second lease; failures are never cached. Price, account, fill, order and exchange submission responses are excluded.

UI caches are NOT admissible Risk evidence. Reader leverage metadata cache 300s pre-existed.

- `integrations/hyperliquid.py::snapshot` is a legacy scalar compatibility view, not canonical authority. Canonical evidence validates numeric values and pool/account identity.
